# n8n Consultant — Projets clients

Projets de sites web avec intégrations n8n pour des clients locaux.

## Projets

### 🍽️ Comptoir du Chef
Site vitrine pour un restaurant avec :
- Pages : accueil, menu, chef, contact, réservations
- Chatbot intégré (n8n)
- Workflows n8n : chatbot, formulaire de contact, réservations

### 🔧 L'Atelier du Métal
Site vitrine pour un artisan métallurgiste.

### 🚗 Prestige Auto
Site vitrine pour un professionnel de l'automobile avec :
- Pages : accueil, services, galerie, tarifs, contact
- Chatbot intégré (n8n)

## Stack
- HTML / CSS / JavaScript (vanilla)
- [n8n](https://n8n.io) pour les workflows d'automatisation
